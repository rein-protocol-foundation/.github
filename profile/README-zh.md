**让 AI 智能体对人与社会更安全。**

Rein Protocol Foundation 汇聚研究者、开发者与社区，通过开源工具、研究和共同学习，推动更安全的 AI 智能体发展。我们关注如何让智能体的行为可理解、权限明确，并让人类监督切实可行。

[官网](https://rein-protocol.org) · [社区（Discord）](https://discord.gg/m8qnWv9XX) · [项目与活动](https://rein-protocol.org/programs)

## 我们的工作方向

- **智能体安全与监督：** 透明度、可观测性、策略控制，以及人类介入机制。
- **开放研究与基础设施：** 可复用工具、可复现的研究产物，以及便于他人检查和继续开发的资源。
- **社区与学习：** 面向 AI 智能体开发者和研究者的线下聚会、工作坊、技术讨论与共享学习材料。

我们是一个 AI 原生组织：智能体在明确的边界内协助研究、协调和运营，人类设定方向并承担责任。了解我们的[治理方式](https://rein-protocol.org/governance)。

## 参与贡献

欢迎参与研究、软件、文档、学习资源和社区活动。

- 改进某个仓库前，请先阅读其 README 和贡献指南，再提交 Issue 或 Pull Request。
- [提出项目或社区活动建议](https://rein-protocol.org/community/contribute)。
- [分享学习资源](https://rein-protocol.org/community/contribute/resources/submit)。
- 如果希望承担持续性的工作，可以[申请成为贡献者](https://rein-protocol.org/community/contribute/apply)。

请遵守我们的[行为准则](https://rein-protocol.org/community/code-of-conduct)。各仓库的许可与复用条款请参阅对应仓库说明。
